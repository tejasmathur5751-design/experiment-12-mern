# Experiment 12 – Full-Stack MERN Application

## Aim
Deploy a full-stack MERN (MongoDB, Express, React, Node.js) application on a cloud platform (Render/AWS/Heroku).

## Architecture
- **M - MongoDB**: Cloud database (Atlas) for persistent task storage
- **E - Express.js**: RESTful API endpoints for CRUD operations
- **R - React.js**: Dynamic frontend user interface with component state
- **N - Node.js**: JavaScript backend runtime

## Running Locally
```bash
npm install
node server.js
```
Open `http://localhost:3000` in your browser.

## Live Demo
Hosted on GitHub Pages with interactive React Task Board and localStorage persistence fallback.
