MERN Stack Overview

M – MongoDB

NoSQL database that stores data in JSON-like documents. Used to store tasks, users and other application data.

E – Express.js

Backend web framework for Node.js. Handles API routes (GET, POST, PUT, DELETE) and connects to MongoDB.

R – React.js

Frontend UI library. Components and state management with useState. This Task Board is built with React.

N – Node.js

JavaScript runtime for the server side. Express runs on Node.js to serve the API and static files.
